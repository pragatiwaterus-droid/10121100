# खानेपानी तथा सरसफाइ उपभोक्ता संस्था व्यवस्थापन सफ्टवेयर (Khanepani ERP)

खानेपानी तथा सरसफाइ उपभोक्ता संस्थाको लागि पूर्ण व्यवस्थापन प्रणाली (Water Users Committee ERP System).

## विशेषताहरू (Features)
- **चलिरहेको मिति (System Operating Date)**: नेपाली वि.सं. क्यालेन्डरमा आधारित।
- **बल्क युनिट इन्ट्री (Bulk Unit Reading)**: अटोमेटिक खपत हिसाब र सेफ बल्क WhatsApp सन्देश।
- **अमाउन्ट इन्ट्री (Payment Collection)**: अटो रसिद नं, नेपाली रकम अक्षरमा र आधिकारिक रसिद प्रिन्ट।
- **केवाईसी दर्ता (Customer KYC)**: अटो ग्राहक आइडी र एक्सेल/CSV बल्क इम्पोर्ट।
- **ऋण तथा किस्ता व्यवस्थापन (Microfinance & Loans)**: अटो ब्याज गणना, किस्ता रसिद, भाखा नाघेको सूचना (Mobile WhatsApp Alert)।
- **बैंक कारोबार (Banking)**: खाता व्यवस्थापन, डिपोजिट/विड्र र बैंकवाइज स्टेटमेन्ट।
- **आम्दानी तथा खर्च लेजर (Income & Expenses)**: शीर्षकगत बजेट तथा स्टेटमेन्ट।
- **कर्मचारी तथा ज्याला (Payroll & Tanker Wage)**: तलब र गाडी पानी बिक्रीको अटोमेटिक ज्याला लिंक।
- **गाडी पानी बिक्री (Tanker Water Sales)**: ग्राहक अनुसार दर र रसिद प्रिन्ट।
- **A4 फिल्ड रिडिङ फाराम (Field Reading Sheet)**: साविक अङ्क भरिएको, हालको अङ्क खाली भएको A4 प्रिन्ट।
- **वित्तीय प्रतिवेदन (Financial Statements)**: नाफा नोक्सान, आय-व्यय, वासलात (Balance Sheet), नगद प्रवाह (Cash Flow) र सन्तुलन परीक्षण।
- **मेन डाटाबेस (Master Ledger)**: मेम्बरवाइज ३६०° विवरण र CSV डाउनलोड।
- **सपोर्ट & ब्याकअप**: १-क्लिक पूर्ण डाटाबेस ब्याकअप र रिस्टोर।

## GitHub बाट निःशुल्क (FREE) अनलाइन गर्ने तरिका (Free Deployment Guide)

### तरिका १: GitHub Pages (१००% नि:शुल्क र आजीवन चल्ने)
हामीले यस रिपोजिटोरीमा स्वचालित वर्कफ्लो `.github/workflows/deploy.yml` तयार गरिसकेका छौँ।

1. यो कोडलाई आफ्नो GitHub मा Push गर्नुहोस्:
   ```bash
   git init
   git add .
   git commit -m "खानेपानी ईआरपी प्रणाली"
   git branch -M main
   git remote add origin https://github.com/तपाईंको-युजरनेम/तपाईंको-रिपो-नाम.git
   git push -u origin main
   ```
2. GitHub मा आफ्नो रिपोजिटोरी खोल्नुहोस्।
3. **Settings** &rarr; **Pages** मा जानुहोस्।
4. **Build and deployment** को **Source** मा **"GitHub Actions"** छान्नुहोस्।
5. केही सेकेन्डभित्रै तपाईंको साइट अनलाइन हुनेछ: `https://<तपाईंको-युजरनेम>.github.io/<रिपो-नाम>/`

---

### तरिका २: Vercel (१-क्लिकमा निःशुल्क लाइभ)
1. [vercel.com](https://vercel.com) मा जानुहोस् र आफ्नो GitHub अकाउन्टमार्फत साइन-इन गर्नुहोस्।
2. **"Add New Project"** मा थिची आफ्नो GitHub रिपोजिटोरी छान्नुहोस्।
3. **Deploy** बटन थिच्नुहोस्।
4. १ मिनेटमै तपाईंलाई आफ्नै निःशुल्क अनलाइन लिङ्क प्राप्त हुनेछ (उदा. `https://khanepani-erp.vercel.app`)।
